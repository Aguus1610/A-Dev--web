Resumen del Proyecto

Contexto y Desafío

EAD Oleohidráulica es una empresa familiar con 25 años de experiencia en sistemas oleohidráulicos, ubicada en Colonia Barón, La Pampa. Necesitaban modernizar su presencia digital para atraer nuevos clientes y profesionalizar su imagen empresarial.

🎯 Desafío Principal

Crear una presencia web profesional que refleje la experiencia y calidad de la empresa, optimizada para atraer clientes industriales (cooperativas, municipios, empresas de transporte) y generar leads calificados.

💡 Solución Implementada

Desarrollo de una landing page moderna y responsive con enfoque en conversión, destacando la experiencia, servicios especializados y casos de éxito, optimizada para SEO local.

Objetivos del Proyecto

  • Presencia Digital Profesional: Crear una imagen web que refleje 25 años de experiencia
  • Generación de Leads: Formulario optimizado para consultas comerciales
  • SEO Local: Posicionamiento para búsquedas en La Pampa y región
  • Responsive Design: Accesibilidad desde todos los dispositivos
  • Carga Rápida: Optimización para conexiones lentas rurales

CSS - Efectos Neon y Glass
/* Glass effect con backdrop-filter */ .glass-effect { background: var(--glass-bg); backdrop-filter: blur(10px); border: 1px solid var(--glass-border); border-radius: 15px; } /* Botones con efecto neon */ .neon-button { border: 2px solid var(--neon-color); color: var(--neon-color); box-shadow: var(--neon-shadow); transition: all 0.3s; } .neon-button:hover { background: var(--neon-color); box-shadow: 0 0 20px var(--neon-color); }
JavaScript - Cursor Personalizado y Efectos
// Cursor personalizado con efectos neon class CustomCursor { init() { this.cursor = document.createElement('div'); this.cursor.className = 'cursor'; document.body.appendChild(this.cursor); document.addEventListener('mousemove', (e) => { requestAnimationFrame(() => { this.cursor.style.left = e.clientX + 'px'; this.cursor.style.top = e.clientY + 'px'; }); }); } }
