# Queries de Google Maps para encontrar PyMEs sin web o con web vieja
# Copiar y pegar en Google Maps (maps.google.com) con sesión iniciada (opcional)

## Cómo usarlas
1. Abrí maps.google.com
2. Pegá la query en el buscador
3. Filtrá por "PyMEs", "talleres", "comercios" de tu zona
4. Vas a la lista de resultados → clickeá cada ficha → mirá si tiene sitio web en la ficha o si el sitio está obsoleto (años 2010/2015)
5. Sacá el nombre, rubro y email/ teléfono de cada uno para tu lista de outreach

## Patrón de detección en cada ficha de Google Maps
Al entrar a ficha de negocio, fijate en:
- **[Sitio web]** field: si viene vacío → es candidato perfecto
- **[Sitio web]** viene con dominio de los años 2010/2015 (ej. `www.empresa2012.com`) → candidato (web muy vieja, oportunidad de renovación)
- Tiene redes sociales activas pero web parada → también oportunidad (unificar marca)
