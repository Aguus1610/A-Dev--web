Resumen del Proyecto

Sistema Integral de Gestión para Talleres

El Sistema de Administración EAD es una aplicación de escritorio desarrollada específicamente para optimizar la gestión operativa del taller EAD Oleohidráulica. Implementa un diseño robusto basado en el patrón MVC y utiliza tecnologías modernas de Python.

Funcionalidades Principales

  • Gestión completa de inventario y stock en tiempo real
  • Administración de clientes y proveedores
  • Seguimiento detallado de trabajos y órdenes de servicio
  • Generación automática de presupuestos personalizados
  • Sistema de reportes con exportación a Excel/PDF
  • Dashboard con estadísticas y gráficos interactivos
  • Control de usuarios y permisos
  • Sistema de respaldos automáticos

Beneficios Operativos

La aplicación ha permitido reducir significativamente los tiempos de generación de presupuestos, mejorar el control de stock y proporcionar insights valiosos sobre el rendimiento del negocio a través de reportes automatizados y visualizaciones de datos.

Dashboard Principal

Pantalla principal con acceso rápido a todas las funcionalidades y estadísticas en tiempo real.

Guía de Uso

1

Inicio de Sesión

Acceda al sistema con sus credenciales. El sistema valida permisos y carga el perfil correspondiente con acceso a las funcionalidades autorizadas.

2

Dashboard Principal

Visualice el resumen ejecutivo con estadísticas clave: trabajos pendientes, stock crítico, ingresos del mes y gráficos de tendencias.

3

Gestión de Clientes

Registre nuevos clientes o edite información existente. Acceda al historial completo de trabajos y genere reportes personalizados por cliente.

4

Control de Inventario

Monitoree stock en tiempo real, configure alertas de mínimos, registre entradas y salidas. El sistema actualiza automáticamente con cada transacción.

5

Creación de Órdenes

Genere órdenes de trabajo con descripción detallada, asignación de técnicos, estimación de tiempos y seguimiento de estado.

6

Generación de Presupuestos

Cree presupuestos automáticamente seleccionando productos y servicios. El sistema calcula totales, aplica descuentos y genera PDF profesional.

7

Reportes y Análisis

Acceda a reportes predefinidos o cree análisis personalizados. Exporte datos a Excel o PDF para presentaciones ejecutivas.

8

Respaldos y Mantenimiento

Configure respaldos automáticos, ejecute tareas de mantenimiento y monitore el rendimiento del sistema desde el panel de administración.

Arquitectura del Sistema

Patrón Modelo-Vista-Controlador (MVC)

La aplicación implementa una arquitectura MVC robusta que separa claramente las responsabilidades y facilita el mantenimiento y escalabilidad del código.

Vista (View)

  • • Interfaz gráfica con Tkinter
  • • Componentes reutilizables
  • • Widgets personalizados
  • • Validación de formularios
  • • Temas y estilos consistentes

Controlador (Controller)

  • • Lógica de negocio
  • • Gestión de eventos
  • • Validaciones
  • • Coordinación entre capas
  • • Manejo de errores

Modelo (Model)

  • • Entidades con Peewee ORM
  • • Base de datos SQLite3
  • • Migraciones automáticas
  • • Relaciones entre tablas
  • • Queries optimizadas

Patrón Observador

Implementado para notificaciones en tiempo real y actualizaciones automáticas de la interfaz cuando cambian los datos. Esto garantiza consistencia entre vistas y mejora la experiencia del usuario.

Decisiones de Diseño

  • SQLite3: Base de datos ligera, sin dependencias externas, ideal para aplicaciones de escritorio
  • Peewee ORM: Simplifica las operaciones de base de datos y proporciona un mapeo objeto-relacional elegante
  • Tkinter: GUI nativa de Python, garantiza compatibilidad y facilita la distribución
  • Modular: Arquitectura en módulos independientes para facilitar testing y mantenimiento
