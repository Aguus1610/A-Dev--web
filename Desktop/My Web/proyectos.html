Sistema de Gestión de Stock

Python Desktop

Aplicación de escritorio completa para control de inventario con interfaz gráfica intuitiva, base de datos local SQLite, generación de reportes PDF y exportación a Excel.

Problema: Control manual de stock con planillas Excel dispersas y riesgo de errores.
Solución: Sistema centralizado con base de datos, interfaz gráfica y reportes automáticos.
Python Tkinter SQLite Peewee ORM
Resultados: Reducción significativa de tiempo en gestión de inventario, eliminación de errores manuales y reportes instantáneos.
